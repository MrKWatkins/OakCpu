# LD rr, rr'

Copies rr' into rr.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `LD SP, HL` | `F9` | 6 |  |
| `LD SP, IX` | `DD F9` | 10 |  |
| `LD SP, IY` | `FD F9` | 10 |  |
