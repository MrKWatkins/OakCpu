# HALT

Suspends the CPU, which executes NOPs until an interrupt or a reset occurs.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `HALT` | `76` | 4 |  |
| `HALT` | `DD 76` | 8 | Undocumented. |
| `HALT` | `FD 76` | 8 | Undocumented. |
