# DI

Disables maskable interrupts by resetting IFF1 and IFF2.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `DI` | `F3` | 4 |  |
| `DI` | `DD F3` | 8 | Undocumented. |
| `DI` | `FD F3` | 8 | Undocumented. |
