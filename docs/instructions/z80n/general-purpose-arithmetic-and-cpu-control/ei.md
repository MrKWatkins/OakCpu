# EI

Enables maskable interrupts by setting IFF1 and IFF2. An interrupt is not accepted until after the following instruction.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `EI` | `FB` | 4 |  |
| `EI` | `DD FB` | 8 | Undocumented. |
| `EI` | `FD FB` | 8 | Undocumented. |
