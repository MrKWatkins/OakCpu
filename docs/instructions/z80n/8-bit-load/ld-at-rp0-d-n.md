# LD (rr + d), n

Stores n at (rr + d).

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `LD (IX + d), n` | `DD 36 d n` | 19 |  |
| `LD (IY + d), n` | `FD 36 d n` | 19 |  |
