# LD A, (nn)

Loads the byte at address nn into A.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `LD A, (nn)` | `3A nn` | 13 |  |
| `LD A, (nn)` | `DD 3A nn` | 17 | Undocumented. |
| `LD A, (nn)` | `FD 3A nn` | 17 | Undocumented. |
