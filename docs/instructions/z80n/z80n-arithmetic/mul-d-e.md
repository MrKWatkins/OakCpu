# MUL D, E

Multiplies D by E, storing the 16-bit result in DE.

## Flags

| Flag | Effect |
| ---- | ------ |

| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

| ----------- | ------ | -------- | ----- |
| `MUL D, E` | `ED 30` | 8 |  |
