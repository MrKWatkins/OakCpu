# MIRROR A

Reverses the order of the bits in A.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

| ----------- | ------ | -------- | ----- |
| `MIRROR A` | `ED 24` | 8 |  |
