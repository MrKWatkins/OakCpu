# EXX

Exchanges BC, DE and HL with their shadow registers BC', DE' and HL'.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `EXX` | `D9` | 4 |  |
| `EXX` | `DD D9` | 8 | Undocumented. |
| `EXX` | `FD D9` | 8 | Undocumented. |
