# OUT (C), 0

Writes zero to the port addressed by BC.

This instruction is undocumented.

## Flags

| Flag | Effect |
| ---- | ------ |

| Z | Unaffected. |

| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |
