# IM 2

Selects interrupt mode 2, in which a maskable interrupt calls the address read from the vector table whose high byte is I and whose low byte is supplied by the interrupting device.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |
