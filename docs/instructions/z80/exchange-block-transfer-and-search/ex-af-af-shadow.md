# EX AF, AF'

Exchanges AF with its shadow register AF'.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `EX AF, AF'` | `08` | 4 |  |
| `EX AF, AF'` | `DD 08` | 8 | Undocumented. |
| `EX AF, AF'` | `FD 08` | 8 | Undocumented. |
