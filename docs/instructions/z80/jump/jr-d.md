# JR d

Jumps to the address d bytes from the next instruction.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `JR d` | `18 d` | 12 |  |
| `JR d` | `DD 18 d` | 16 | Undocumented. |
| `JR d` | `FD 18 d` | 16 | Undocumented. |
