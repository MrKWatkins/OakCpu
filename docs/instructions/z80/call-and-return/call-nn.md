# CALL nn

Pushes the address of the next instruction onto the stack, then jumps to nn.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `CALL nn` | `CD nn` | 17 |  |
| `CALL nn` | `DD CD nn` | 21 | Undocumented. |
| `CALL nn` | `FD CD nn` | 21 | Undocumented. |
