# RET

Pops the return address from the stack into PC.

## Flags

| Flag | Effect |
| ---- | ------ |
| S | Unaffected. |
| Z | Unaffected. |
| Y | Unaffected. |
| H | Unaffected. |
| X | Unaffected. |
| PV | Unaffected. |
| N | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | T-States | Notes |
| ----------- | ------ | -------- | ----- |
| `RET` | `C9` | 10 |  |
| `RET` | `DD C9` | 14 | Undocumented. |
| `RET` | `FD C9` | 14 | Undocumented. |
