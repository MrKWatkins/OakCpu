# JMP (abs)

Jumps to the address stored at address abs. If abs is the last byte of a page, the high byte of the address is read from the first byte of the same page rather than the next one.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Unaffected. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Unaffected. |
| Z | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `JMP (abs)` | `6C abs` | 5 |  |
