# ORA (zp),Y

Bitwise ORs A with the byte at Y plus the address stored at zero page address zp. Takes an extra cycle if adding Y crosses a page.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Set if bit 7 of A is set, otherwise reset. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Unaffected. |
| Z | Set if A is zero, otherwise reset. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `ORA (zp),Y` | `11 zp` | 5 or 6 |  |
