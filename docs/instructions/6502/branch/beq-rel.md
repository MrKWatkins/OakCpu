# BEQ rel

Branches to the address of the next instruction plus the signed displacement rel if the Z flag is set. Takes an extra cycle if the branch is taken, and another if it crosses a page.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Unaffected. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Unaffected. |
| Z | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `BEQ rel` | `F0 rel` | 2 or 3 or 4 |  |
