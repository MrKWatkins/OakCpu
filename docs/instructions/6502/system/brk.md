# BRK

Pushes the address of the byte after the padding byte following the opcode, then the processor status with the B flag set, onto the stack, sets the interrupt disable flag and jumps to the address at the IRQ vector, 0xFFFE.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Unaffected. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Set. |
| Z | Unaffected. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `BRK` | `00` | 7 |  |
