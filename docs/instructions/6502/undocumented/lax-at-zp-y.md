# LAX (zp),Y

Loads both A and X with the byte at Y plus the address stored at zero page address zp. Takes an extra cycle if adding Y crosses a page.

This instruction is undocumented.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Set if bit 7 of A is set, otherwise reset. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Unaffected. |
| Z | Set if A is zero, otherwise reset. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `LAX (zp),Y` | `B3 zp` | 5 or 6 |  |
