# TAY

Copies A into Y.

## Flags

| Flag | Effect |
| ---- | ------ |
| N | Set if bit 7 of Y is set, otherwise reset. |
| V | Unaffected. |
| B | Unaffected. |
| D | Unaffected. |
| I | Unaffected. |
| Z | Set if Y is zero, otherwise reset. |
| C | Unaffected. |

## Opcodes

| Instruction | Opcode | Cycles | Notes |
| ----------- | ------ | ------ | ----- |
| `TAY` | `A8` | 2 |  |
