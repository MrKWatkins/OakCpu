  - instruction: DAA
    defined_by: Z80
    group: General-Purpose Arithmetic and CPU Control
    documentation: Adjusts A to binary coded decimal after an addition or subtraction of binary coded decimal values, using the N, H and C flags to choose the adjustment.
    undocumented: false
    page: general-purpose-arithmetic-and-cpu-control/daa.md
    flags:
      S:
        effect: changed
        documentation: Copied from bit 7 of A.
      Z:
        effect: changed
        documentation: Set if A is zero, otherwise reset.
      Y:
        effect: changed
        documentation: Copied from bit 5 of A.
      H:
        effect: changed
        documentation: After an addition, when the N flag is reset, set if the low nibble of A was greater than 9 before the adjustment, otherwise reset. After a subtraction, when the N flag is set, set if the H flag was set and the low nibble of A was less than 6 before the adjustment, otherwise reset.
      X:
        effect: changed
        documentation: Copied from bit 3 of A.
      PV:
        effect: changed
        documentation: Set if A has even parity, otherwise reset.
      N:
        effect: unaffected
        documentation: Unaffected.
      C:
        effect: changed
        documentation: Set if the C flag was set or A was greater than 0x99 before the adjustment, otherwise reset.
